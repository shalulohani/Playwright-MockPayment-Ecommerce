# 🧪 Playwright MockPayment Ecommerce

End‑to‑end test automation framework built with **Playwright** for a mock e‑commerce checkout and payment flow.

---

## 🚀 Features
- Headless browser testing for CI pipelines  
- Integrated **Allure** and **Playwright HTML** reports  
- Modular test structure with reusable page objects  
- CI/CD setup via **GitHub Actions**  
- Clean folder structure for scalable test suites
